# Тренажёр Т-Банка: журнал ситуаций

Кейс требует пройти тренажёры в личном кабинете и выделить 3-5 ключевых действий или черт, которые помогли решить проблему. Каждый участник заносит сюда каждую пройденную ситуацию **дословно** (текст ситуации, наш ответ, отзыв бота). Не придумываем и не пересказываем отзыв бота своими словами.

Статус: **ждём данные от команды** (на 27.10 ситуации ещё не внесены).

## Шаблон записи

```
### T0_  <короткое название ситуации>
Кто проходил:            Дата:
Тип ситуации: срочно / страшно / несправедливо / тяжело / снова
Ситуация (текст бота):
Наш ответ:
Оценка бота:
Отзыв бота (дословно):
Что сработало:
Что бот предложил улучшить:
Ключевые действия (коды из таблицы ниже):
```

## Сводка действий (заполняем после 5+ ситуаций)

Считаем, в скольких ситуациях действие помогло (по отзыву бота) или его не хватило.

| Код | Действие или черта | Помогло, N из M ситуаций | Не хватило, N из M | Цитата из отзыва бота |
|---|---|---|---|---|
| D1 | Сначала посмотрел контекст (история, операции), а потом спросил |  |  |  |
| D2 | Назвал эмоцию и переформулировал проблему своими словами |  |  |  |
| D3 | Задал уточняющий вопрос до инструкции |  |  |  |
| D4 | Дал план: что сделаю я, что нужно от клиента, когда будет результат |  |  |  |
| D5 | Честно объяснил ограничение и предложил альтернативу |  |  |  |
| D6 | Не перебивал, не отправлял шаблон сразу |  |  |  |
| D7 | Вернулся с результатом сам, без повторного обращения клиента |  |  |  |
| D8 | Предложил жест заботы или компенсацию с обоснованием |  |  |  |

Коды D1-D8 это наши гипотезы из исследования (отзывы и практики). Тренажёр их подтверждает или опровергает; в презентацию идут только подтверждённые 3-5.
