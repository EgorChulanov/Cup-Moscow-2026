# Требования к сдаче и критерии оценки

Источник: посты организаторов в канале и чате секции Т-Банка (26-27.10.2026), правила Changellenge.

## Формат

| Требование | Значение |
|---|---|
| Дедлайн | 2 ноября 2026, 12:00 МСК |
| Кто загружает | один участник команды, в личном кабинете, кнопка «Загрузить решение» |
| Формат | один PDF или архив до **18 МБ**; ссылки на облако не принимаются |
| Основная часть | **8 слайдов**, включая титульный и слайд с резюме команды |
| Приложения | не ограничены и не считаются; лучше внутри презентации; Excel с расчётами можно приложить отдельно, назвать так же, как презентацию |
| Имя файла | `CupMoscow2026-Т-Банк-<НазваниеКоманды>` |
| Защита | на 1 туре нет, оценка асинхронная |
| Результаты | 10 ноября 2026, 14:00 МСК, на почту |
| Q&A с экспертами Т-Банка | 30 октября 2026, 15:00 МСК; вопросы в форму до 30.10, 10:00 |
| Тренажёр | кейс-тренажёр в ЛК (бот оценивает ответ). Обязательный кейс партнёра для всей команды даёт +1 балл |

## Критерии (оценка 1-5 по каждому)

### 1. Широта анализа
- иерархия причин проблемы на 3-5 уровней;
- 3-5 вариантов решения;
- выделены приоритетные факторы выбора;
- по каждому решению рассмотрены финансы, риски и план действий.

### 2. Глубина анализа
- достаточно факторов для сравнения вариантов;
- варианты сравниваются по единой структуре факторов;
- выбор аргументирован фактами и данными со ссылками на источники;
- системное понимание проблематики и специфики отрасли.

### 3. Структура и логика
- последовательная логика без скачков;
- единая логика аргументации и структура;
- нет провалов в аргументации;
- выводы и рекомендации следуют из анализа.

### 4. Соответствие задаче
- отвечаем строго на вопросы кейса;
- подробный ответ на все подзадачи;
- понимание бизнеса и потребностей клиента;
- оригинальный, но реализуемый подход.

### 5. Качество презентации
- понятная структура каждого слайда;
- главная мысль ясна и «продаёт» решение;
- деловой стиль и цветовая гамма;
- нет опечаток, помарок, избытка текста.
