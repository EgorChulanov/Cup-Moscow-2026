## Как пересобрать доску Miro

```bash
python3 cjm/miro_svg.py      # cjm/out/miro.svg и miro_1..3.svg (по фрейму)
```

Файлы загружаются в Miro через Canvas Composer (`canvas_create_from_svg`). На новой доске загружать по одному фрейму, на существующей менять точечно через `canvas_update_from_svg`, чтобы не задвоить элементы.
