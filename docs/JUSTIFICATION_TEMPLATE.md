# Шаблон-обоснование для специалиста поддержки

Заполняется за 3-5 минут, когда специалист: (а) хочет сделать уступку выше своего порога или (б) видит проблему продукта или процесса, которая может повторяться. Логика повторяет вопросы из кейса: что происходит, почему важно, какое изменение, на какой результат рассчитываем, по каким признакам поймём, что работает.

## Шаблон

```
1. ЧТО ПРОИЗОШЛО (факт, без оценок)
   Клиент / сегмент:              Тип ситуации: Срочно / Страшно / Несправедливо / Тяжело / Снова
   Что случилось:
   Ссылка на диалог и операции:

2. ПОЧЕМУ ЭТО ВАЖНО (последствия)
   Для клиента (деньги, время, эмоции):
   Для банка: повторные обращения ____ x 274 ₽; риск ухода; риск жалобы в ЦБ или финомбудсмену
   Масштаб: похожих обращений за 30 дней ____ (поиск по тегу причины или ИИ-помощник)  [1 случай = сигнал, 10+ = паттерн]

3. ЧТО ПРЕДЛАГАЮ
   (а) Для этого клиента: уступка ____ ₽ / действие ____
       Порог по формуле: 0,20 x доля ухода x прибыль клиента в год x лет + ожидаемые повторы x 274 ₽ = ____ ₽
   (б) Для продукта или процесса: что изменить ____  Кому: продукт / риски / методология / ИТ

4. НА КАКОЙ РЕЗУЛЬТАТ РАССЧИТЫВАЕМ
   Метрика и ожидаемое изменение: повторных обращений по теме и жалоб меньше, удержание выше
   Сколько стоит изменение (оценка или «нужна оценка команды»):

5. КАК ПРОВЕРИМ
   Признак, что работает:              Через сколько проверить:
   Что может ухудшиться (контрольная метрика):
```

## Пример 1. Уступка: вернуть 98 ₽ за недоплату 5 копеек

```
1. Клиентка 6 лет в банке, кредитная карта, просрочек не было. Тип: Несправедливо.
   Списано 98 ₽ за просрочку из-за недоплаты 0,05 ₽. Просит вернуть.
2. Клиент: деньги небольшие, но ощущение несправедливости, готова закрыть карту.
   Банк: без уступки ожидаем 2 повторных обращения (2 x 274 ₽ = 548 ₽) и риск ухода.
   Масштаб: похожих обращений «недоплата меньше 1 ₽» за 30 дней: проверить по тегу.
3. (а) Вернуть 98 ₽ сейчас. Порог: 0,20 x 0,25 x 5 220 ₽ x 1 год + 548 ₽ = 809 ₽. 98 ₽ меньше 809 ₽, поэтому решаю сам.
   (б) Продукт: не начислять штраф, если недоплата меньше 1 ₽, либо предлагать автоплатёж полной суммы
       при подключении карты. Кому: продукт «Кредитные карты», риски.
4. Повторных обращений по теме меньше; удержание клиентов кредитных карт с такой ситуацией выше.
   Стоимость (б): потеря штрафов с недоплат меньше 1 ₽ (нужна оценка команды продукта).
5. Признак: обращений по теме за месяц меньше в 2 раза. Проверить через 2 месяца.
   Контрольная метрика: доля просрочек по кредитным картам не растёт.
```

## Пример 2. Сигнал в продукт: кешбэк не начисляется в категории

```
1. Клиентка пишет третий раз. Тип: Снова. 4 покупки в категории «Аптеки» не попали в кешбэк,
   магазин передаёт другой код категории (MCC). Начислил 1 240 ₽ вручную.
2. Клиент: «меня не слышат», сумма уже вторична. Банк: 3 обращения x 274 ₽ = 822 ₽ на один случай.
   Масштаб: по тегу «кешбэк, аптеки, MCC» за 30 дней 340 обращений (пример значения, взять из системы).
3. (б) Добавить MCC этой сети в правило категории; до исправления подсказки предлагают начислить вручную.
   Кому: продукт «Кешбэк», ИТ.
4. Повторных обращений по теме нет; экономия ≈ 340 x 1,5 x 274 ₽ ≈ 140 тыс. ₽ в месяц, плюс удержание.
5. Признак: обращений по тегу нет 2 недели после исправления. Контрольная метрика: расходы на кешбэк в категории.
```

## Порог уступки (лист «Порог компенсации» финмодели)

| Сценарий | Расчёт | Порог |
|---|---|---|
| Консервативный: 1 год ценности, 25% намерения превращается в уход | 0,20 x 0,25 x 5 220 ₽ + 2 x 274 ₽ | **809 ₽** |
| Расширенный: 3 года, 50% | 0,20 x 0,50 x 15 660 ₽ + 2 x 274 ₽ | **2 114 ₽** |

Источники: разница намерения уйти 25% и 5% (SQM Group); прибыль активного клиента 5 220 ₽ (Т-Технологии, 2025, research/02); стоимость обращения 274 ₽ (research/02, п. 2.3).

Правило: до порога и при спорности или вине банка специалист решает сам. Выше порога, при признаках злоупотребления или в случаях мошенничества (средняя сумма 18,6 тыс. ₽, ЦБ 2025) решение по шаблону через руководителя или по правилам «Защитим или вернём деньги».
